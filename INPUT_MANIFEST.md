# SHIFTWISE competition source bundle
All source datasets are simulated and do not describe actual Costco employees, service or wages.

- `reference/`: authoritative case PDF and original student Excel workbook
- `csv/`: original case CSV inputs and submission template
- `docs/`: original README, assumptions, and data dictionary
- `sql/`: original database build, validation and starter query scripts

Source datasets outrank earlier ChatGPT analysis. A separate prior research archive may be useful for hypotheses but its findings need independent reproduction.
