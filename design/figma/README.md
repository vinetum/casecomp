# Download the SHIFTWISE Figma design

If chat attachment downloads fail, download the files directly from this repository while signed in to GitHub.

## Smallest download: complete native plugin (73 KB)

1. Open `SHIFTWISE_FIGMA_PLUGIN_ONLY.zip` in this folder.
2. Click **Download raw file** (the down-arrow button at the upper-right of the file viewer).
3. Unzip it in Finder. Keep manifest.json and code.js together.
4. Open a blank Figma Design file in the Figma desktop app.
5. Choose **Plugins → Development → Import plugin from manifest…** and select `SHIFTWISE_PLUGIN/manifest.json`.
6. Run **SHIFTWISE — Complete Dashboard Design** from Development plugins.

This small ZIP includes all 39 artboards and the native creation code, not just a sample.

## Full review package (about 9 MB)

Download `SHIFTWISE_FIGMA_COMPLETE.zip` with the same down-arrow button for the native plugin, offline browser preview, all SVG/PNG screens, design book, source provenance and verification reports.

No code editing is necessary. The local browser preview and mocked Figma API checks passed; actual Figma account import remains unverified. This is a prepared visual prototype, not live Python optimization. This branch adds design downloads only and does not alter or deploy the working application.
